# Laplace NS · FGO TA 概率计算器

**Laplace NS**（Laplace Next Station）：击破概率 · 发牌概率 · buff 成功率 · 送人概率 · 综合击破概率。

网页：<https://ada-yl5326.github.io/fgo-prob-calc/>

**第一次用？** 看 [使用指南（GUIDE.md）](GUIDE.md)：每个页面、每种用法的图文说明。网页底部的「使用指南」也能打开同样的内容。

## 功能

- **击破概率**：输入四张卡（First / Second / Third / EX）的均伤、击破血量和 SL 次数，精确计算一回合击破的概率
  （统计全部 200⁴ 种伤害随机数组合，没有模拟误差），并画出总伤害分布和击破概率曲线；
  可以加最多 5 个 AOE 其他目标（群体伤害打到的其他敌人，全部击破才算）。
  - **从 Laplace 截图导入**：选 Laplace（Chaldea 的战斗模拟）战斗记录的截图，在本机自动识别每张卡的伤害，
    每个回合生成一个伤害组；用血量和总伤害两种方法核对识别结果，多血条、复活也能对上。
- **发牌概率**：选择场上人数、最多 3 名从者的配卡、纹章和每个回合要发到的牌，计算第 1 回合或同一轮洗牌里
  前 2 ~ 3 个回合（共享发牌）发到这些牌的概率；每个回合、每名从者分别选包含 / 仅含，并列出计算过程；
  几种发牌都可以接受时用「或者」加最多 5 种条件（容斥原理精确计算，不是直接相加）。
- **buff 成功率**：魅惑、眩晕、降防这类不是必中的技能，一组最多 10 个，全部成功才算成功；
  每个 buff 可以单独 SL；一个技能判定好几次（例如全体眩晕「至少命中 2 个」）用二项分布计算。
- **送人概率**：敌方行动阶段让敌人打倒我方指定从者（送人）的概率。最多 6 个敌人，可以设置行动次数、普攻和暴击、
  牌型、宝具、开技能概率；我方可以设置 HP、被攻击权重、嘲讽、无敌、战续，以及「受击要求」（要挨几下、挨什么样的攻击）。
  结果给出成功率、SL 0 ~ 5 次对照表和失败原因。
- **综合击破概率**：把保存好的伤害组、发牌组、buff 组、送人组放进各个回合，按「发牌 → 我方 buff → 击破 → 敌方 buff → 送人」
  的顺序，把全部「世界线」精确走一遍，算出整个多回合方案从头到尾成功的概率；
  可以按发到的牌分配不同的打法，设定 buff 没挂上时的备用打法，以及额外的 SL 次数。
- **工作目录**：左上角按钮打开侧边栏，保存、切换多份工作记录；可以用二维码、分享链接、分享码或工作文件分享给别人，
  对方在网页里「导入」即可（二维码可以直接从截图读取，不需要相册权限）。每个页面的结果都能生成一张分享图片。

计算和截图识别全部在浏览器里完成，不上传任何数据。
iPhone 用 Safari 打开网页 →「分享」→「添加到主屏幕」，之后像 App 一样从桌面打开，断网也能用。

非官方粉丝工具，与游戏官方无关。本仓库只用于发布网页，由脚本自动更新。
