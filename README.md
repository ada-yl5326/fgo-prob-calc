# Laplace NS · FGO 击破与发牌概率

**Laplace NS**（Laplace Next Station）：击破概率 · 发牌概率 · 综合击破概率。

网页：<https://ada-yl5326.github.io/fgo-prob-calc/>

**第一次用？** 看 [使用指南（GUIDE.md）](GUIDE.md)：每个页面、每种用法的图文说明。网页底部的「使用指南」也能打开同样的内容。

- **击破概率**：输入四张卡（First / Second / Third / EX）的均伤、击破血量和 SL 次数，精确计算一回合击破的概率
  （统计全部 200⁴ 种伤害随机数组合，没有模拟误差），并画出总伤害分布和击破概率曲线；
  可以加最多 5 个 AOE 其他目标（群体伤害打到的其他敌人，全部击破才算）。
- **发牌概率**：选择场上人数、最多 3 名从者的配卡、纹章和每个回合要发到的牌，计算第 1 回合或同一轮洗牌里
  前 2 ~ 3 个回合（共享发牌）发到这些牌的概率；每个回合、每名从者分别选包含 / 仅含，并列出计算过程；
  几种发牌都可以接受时用「或者」加最多 5 种条件（容斥原理精确计算，不是直接相加）。
- **综合击破概率**：把保存好的伤害组、发牌组放进各个回合，计算整个多回合方案的综合击破率；
  发牌组有几种条件、各牌型伤害不同时，可以按条件分配伤害（还可以设定没发到想要的牌时的保底打法）。
- **工作目录**：左上角按钮打开侧边栏，保存、切换多份工作记录；可以用二维码、分享链接、分享码或工作文件分享给别人，
  对方在网页里「导入」即可（二维码可以直接从截图读取，不需要相册权限）。

计算全部在浏览器里完成，不上传任何数据。
iPhone 用 Safari 打开网页 →「分享」→「添加到主屏幕」，之后像 App 一样从桌面打开，断网也能用。

非官方粉丝工具，与游戏官方无关。本仓库只用于发布网页，由脚本自动更新。
