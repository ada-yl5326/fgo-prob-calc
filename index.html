SL 次数与击破率
SL n 次 = 一共 n + 1 次机会，至少击破一次：击破率 = 1 − (1 − 单次击破率)^(n+1)
击破 未击破
单次 SL 后
计算规则与使用说明
  • 每个伤害维度（一张卡、一次攻击）的伤害 = 向下取整(均伤 × 随机数)，随机数从 0.900 ~ 1.099 共 200 个值中等概率抽取，每个维度独立；总伤害 ≥ HP 即为击破。统计了全部 200n 种组合（n = 维度数），取整方式与 Excel 计算器相同。
  • 伤害维度：每个单独抽随机数的伤害算一个维度。主目标默认 4 维（First / Second / Third / EX），AOE 目标默认 1 维，都可以用 − / ＋ 增减，1 ~ 12 维。6 维以内是精确值；7 维以上是浮点近似（误差约 10⁻¹³，显示的位数看不出差别）。维度多、伤害高时要算一会儿（10 维、均伤之和 1000 万时约 1 秒多），停下输入后才开始算。
  • 均伤可以带小数，不出的卡留空（留空 = 这一维伤害为 0）。固伤不乘随机数：要算固伤时，HP 填「击破血量 − 各卡固伤之和」。
  • AOE 其他目标：群体攻击同时打到的其他敌人，每行填打到它的伤害（默认 1 维，可以增减）和它的 HP，最多 5 个。每个目标单独抽随机数，全部击破才算：击破率 = 主目标 × 各 AOE 目标的击破率，SL 也按这个算。图表画的是主目标的总伤害。
  • SL 次数：没击破时可以重来几次。只适用于重来后发到的牌不变、只重新抽伤害随机数的情况。SL n 次 = 一共 n + 1 次机会，击破率 = 1 − (1 − 单次击破率)^(n+1)。不用时留空，也可以点右边的 − / ＋ 调整。
  • 伤害组：可以保存好几组输入（例如每个回合一组、每种牌型一组），在「综合击破概率」页放进各个回合。
  • 伤害分布：柱子 = 总伤害落在这一段的概率；点按某处，显示总伤害 ≥ 该处的概率（即 HP 为该处时的击破率）。击破概率曲线：高度 = HP 为 X 时的击破率，紫色是 SL 后的击破率；点按或滑动可以查看任意 HP。有 AOE 目标时，曲线高度已乘上 AOE 目标的击破率，纵轴跟着最高点缩放。
  • 添加到主屏幕后像 App 一样使用，断网也能用。iPhone：Safari →「分享」→「添加到主屏幕」；安卓：浏览器菜单 →「添加到主屏幕」或「安装应用」。右上角的按钮切换外观（自动 / 浅色 / 深色）。
  • 分享图片：每页结果下面的「生成分享图片」把这一页的主要信息排成一张图片，可以保存或复制后发给别人（想让别人导入同样的设置，用工作目录的导出）。
  • 工作目录（左上角）：把全部伤害组、发牌组、buff 组、送人组和方案存成一个工作目录，可以存好几个、随时切换；导出成文件 / 分享码 / 分享链接 / 二维码发给别人，或者导入别人分享的内容（可以直接从相册选二维码图片，不需要相册权限）。数据只存在这台设备的浏览器里，重要的请导出成文件备份。

发牌规则与说明
  • 牌库：3 人上场 15 张，每回合发 5 张，3 个回合发完后重新洗牌；2 人上场 10 张，2 个回合发完。
  • 回合：「第 1 回合」只看一个回合；「1–2 回合」「1–3 回合」是同一轮洗牌的几个回合一起算，前面发出的牌后面不会再发，各回合的条件同时满足才算。
  • 从者：从者1 要选配卡；从者2、3 可以不指定，不指定时他们的牌只看张数。不同从者的牌互不替代。
  • 包含 / 仅含（点「第 n 回合」下面的小按钮切换）：选了牌时，包含 = 至少发到这些牌，仅含 = 这名从者发到的牌恰好是这些；没选牌时，不限 = 发不发都行，不能有 = 这名从者一张牌都不能发到。
  • 或者：几种发牌都可以接受时（例如 BA、BQ、BB 都行），点「＋ 或者」加一种条件，最多 5 种，满足任意一种即可。不能把各条件的概率直接相加（同一手牌可能同时满足几种，会重复计算），这里用容斥原理精确计算，过程见「计算过程」。几种牌型打出的伤害不同时，到「综合击破概率」页用「按条件分配伤害」。
  • 纹章：开了纹章的牌只认这一张；同色几张都开纹章时按 ①②③ 区分，互不替代。
  • 换人、从者退场、洗牌技能会改变牌库，这里不算；退场后重新洗牌，请在「综合击破概率」页用新的发牌组表示。

计算过程
buff 规则与使用说明
  • buff 成功率：给敌方或我方加 buff / debuff 时，有的不是必中的。一个 buff 组可以放好几个 buff，全部成功才算成功：成功率 = 各 buff 的成功率相乘。
  • 普通 buff：直接填成功率。
  • 二项分布 buff：一个技能判定好几次（例如一次打 3 个敌人），命中次数「至少 / 恰好 / 至多」x 次才算成功。每次的成功率可以相同，也可以分别填（例如几个敌人的弱体耐性不同）。 不要把一个技能拆成几个普通 buff：SL 时这几次判定会一起重抽，拆开算会偏高，「至少 2 个」也没法表示。
  • SL 次数：每个 buff 自己的 SL 次数。技能一个一个放，一个 buff 失败时可以 SL 重抽它，成功后再放下一个，前面的结果保留：SL n 次后 = 1 − (1 − 单次成功率)^(n+1)。
  • 两个结果：放在综合页的「我方 buff」一行时，用各自 SL 后相乘的成功率；放在「敌方 buff」一行（敌方行动阶段、送人之前的判定）时，每条世界线只判定一次、不能单独 SL，用单次成功率相乘。
  • buff 组：可以保存好几组，放进「综合击破概率」页。

送人规则与使用说明
  • 送人：在敌方行动阶段让敌人打倒我方指定的从者。这一页算的是敌方这一回合行动完后，达成要求的概率（统计全部随机情况的精确值）。
  • 敌人（最多 6 个）按行动顺序轮流行动：1st、2nd … 各行动一次，再回到 1st；行动次数用完的跳过。用 ↑ ↓ 调整顺序。
  • 伤害 = 向下取整(均伤 × 颜色倍率 × 伤害倍率 × 随机数)，随机数和我方一样是 0.900 ~ 1.099 的 200 个值；全体攻击打到的每名从者各自抽随机数。
  • 暴击：每次攻击按暴击率判定，暴击时用暴击均伤。牌型：每次攻击按牌型里各颜色的张数 ÷ 5 抽颜色（B ×1.5、A ×1、Q ×0.8）。开技能：只在这个敌人的第 1 次行动判定，没有伤害，也算一次行动。
  • 宝具：选预设在第几次行动放；宝具不判定开技能、暴击，不受牌型影响；不填均伤 = 无伤害宝具。
  • 合法目标：每次行动（开技能除外）先选目标：场上有嘲讽的从者时只选有嘲讽的；被这个敌人打出战续、带着「对它不合法」状态的从者不能选。没有合法目标时这次行动被跳过，行动次数照样用掉，预设的动作（例如宝具）顺延到下一次。全体攻击选定目标后打到所有在场的从者。
  • 被攻击权重：在合法目标里按权重随机选，选中的概率 = 自己的权重 ÷ 合法目标的权重之和；空着 = 1。
  • 角色：要退场（没退场就失败）、可以退场（无所谓）、不能退场（退场就失败）、不会死（不填 HP）。至少要有一名「要退场」或「不能退场」（或者设了受击要求）；只设「不能退场」时，算的是他们都没退场的概率。
  • 受击要求（从者右上角的开关）：指定这名从者挨几下、挨什么攻击，每条都满足才算成功。每条 = 类型（B / A / Q / 普通 / 宝具）+ 暴击（不限 / 暴击 / 不暴击）+ 至少 / 恰好 / 至多 n 次。先满足特殊条目：对上的「至少 / 恰好」B / A / Q 条目还没满足时，这一下不计入「普通」，满足以后多出来的也计入「普通」；「至多」条目不挡「普通」（例：「暴击 B 至少 2 次」+「普通 至少 1 次」= 挨 3 下以上、其中至少 2 下暴击 B）。被无敌挡掉、全体攻击打到、无伤害宝具都算一次；没有敌人开牌型时只能选普通、宝具。只看受击要求时（没有要退场、不能退场的从者），敌方均伤、可以退场的从者 HP 都可以不填。
  • 无敌：每次受到攻击，伤害为 0、次数 −1（无伤害宝具不消耗）。战续：累计伤害达到 HP 时以战续血量复活、伤害重新累计，可以有几次；战续不算退场。被普通攻击或暴击打出战续，或者有嘲讽的从者被宝具打出战续，会获得「对这个敌人不合法」，持续一次行动；被宝具打出战续时场上只剩他一人且有后备队友，也一样。
  • 中断回合：没有后备队友、场上只剩一名从者时他被打出战续；或者一开始有嘲讽的从者，后来全部退场了。
  • SL 次数：送人失败时可以重来几次，每次重新抽全部随机数：成功率 = 1 − (1 − 单次成功率)^(n+1)。
  • 设置特别复杂（多个敌人、多次行动、每人要挨很多下）时精确计算量太大，会改为模拟并标明「模拟值」和误差。
  • 送人组：可以保存好几组设置，以后可以放进「综合击破概率」页的敌方行动阶段。

计算过程
计算规则与使用说明
  • 世界线：一条世界线 = 从头到尾的一次完整经过（包括在哪里失败、在哪里 SL）。综合击破概率 = 能走到成功的世界线的概率之和。随机的分叉（判定成功 / 失败、发到哪种牌）按概率相加；自己选的分叉（用哪种方法救、先试哪种出牌、用哪组 buff）每种都走一遍，取结果最好的。完整规则见 GitHub 上的《世界线规则》。
  • 回合：每列一个回合，从上往下是结算顺序：发牌 → 我方 buff → 击破 → 敌方 buff → 送人。空着的格子 = 不需要（100%）。没放 buff 组、没设额外 SL 的方案，结果和 v0.9 相同。
  • 我方 buff：buff 一个一个判定，失败时用这个 buff 自己的 SL 次数重抽（只重抽它，前面的保留）；之后换出牌也不会重新放技能。buff 组全部成功 → 用「击破」格的伤害组；有失败 → 用下面「我方 buff 没成功时用」格的伤害组（空着 = 失败）。
  • 击破 → 敌方 buff → 送人：换出牌 = 一条新的世界线，击破、敌方 buff、送人一起重新判定。换出牌的次数 = 伤害组的 SL 次数（没放伤害组时 = 送人组的 SL 次数）；送人组自己的 SL 不另外算。敌方 buff 每条世界线判定一次；全部成功 → 用「送人」格的送人组，有失败 → 用「敌方 buff 没成功时用」格的送人组（空着 = 失败）。
  • 额外 SL：每个阶段格子（我方 buff / 击破 / 敌方 buff / 送人）下面有「＋额外 SL」，给这一回合的这个阶段加几次 SL，只能在这个阶段用；「全局额外 SL」整个方案共用。发牌组下面也有「＋额外 SL」：看到牌之后可以重新发牌，但只能用发牌阶段专用的次数（全局额外 SL 不能用来重新发牌）。用在哪一步，就只重抽那一步和后面的（例如送人失败时用一次，击破的结果保留）。有全局额外 SL 时，前面的回合用掉了后面就少了，结果不能拆成各回合相乘。
  • 发牌组占几个回合由它的「回合」设置决定（1 / 2 / 3 列），放在第 k 回合表示第 k 回合重新洗牌。同一个组可以用在好几个回合。
  • 洗牌：3 人每 3 回合洗一次牌（2 人每 2 回合），有从者退场时下一回合立刻洗牌。发牌组放在不是正常洗牌的回合时，会提示「需要前一回合有从者退场」，请自己确认。
  • 按条件分配：发牌组有「或者」的几种条件、各牌型的打法不同时，在被它占用的回合点「按条件分配」，这一列分成「回合 / 条件 1 … / 其他」几小列，每小列从上往下就是一种打法。条件格的伤害组空着 = 不需要击破；其他格空着 = 失败；我方 buff、敌方 buff、送人空着 = 跟随「回合」那一小列。
  • 满足好几种条件时：同一个伤害组 = 同一种出牌，只试一次；不同伤害组 = 不同出牌，各试一遍（任意一种成功即可）。用不同 buff 组的打法只能选一种（技能只能放一次）。过程列在「计算过程」里。
  • 发牌组占好几个回合、几种条件又在不同回合有差别时，按条件分配相当于「看到后面的牌再决定按哪种打」，结果可能略偏高。
  • 操作：按住组拖到格子里，或者先点组、再点格子；放好的组按住左边的 ⠿ 可以拖到别的格子，点 × 移除。点「合并」把分了条件的回合变回一列。
